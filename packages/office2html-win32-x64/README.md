# @deckflow/office2html-win32-x64

The Windows x64 `office2html` runtime distributed as part of the DeckRender Community open-source project.

This is a platform package used automatically by `@deckflow/deckrender`. Install the main package rather than depending on this package directly. The executable is stored at `bin/office2html.exe` and exposed as the `office2html` command.
